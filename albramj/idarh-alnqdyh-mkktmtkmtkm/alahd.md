# شاشةالعهد المؤقتة-تقرير العهد المؤقتة-تقرير حركات العهد

## شاشة العهد المؤقتة  <a href="#user-content-d8-b4-d8-a7-d8-b4-d8-a9-d8-a7-d9-84-d8-b9-d9-87-d8-af-5b-5d" id="user-content-d8-b4-d8-a7-d8-b4-d8-a9-d8-a7-d9-84-d8-b9-d9-87-d8-af-5b-5d"></a>

**الغرض من هذه الشاشة هو تسجيل العهدة التى تخرج من الخزينة لحين تسوية هذه العهده**            &#x20;

**يتم انشاء العهد المؤقتة بالخطوات التالية**     &#x20;

&#x20;   1- يتم اختيار الموظف المراد عمل عهدة له ويظهر اسم الموظف اتوماتيكي بعد اختياره                  2-يتم اختيار العملة                                                                                               &#x20;

&#x20;        3-من الممكن ربط العهدة بمشروع محدد ولكن ليس الزامي                                          &#x20;

&#x20;       4-يتم ادراج تاريخ العهدة وتاريخ التسوية المتوقع                                                       &#x20;

&#x20;      5- يتم ادراج الوصف                                                                                              &#x20;

6- يتم ادخال القيمة                                                                                              &#x20;

&#x20;      7- يتم ادخال رقم المستند   والمسلسل يظهر اتوماتيكي بعد الحفظ                                                                                                &#x20;

&#x20;                                                                                      &#x20;

&#x20; **يتم البحث عن العهد المؤقتة بالخطوات التالية :-**                                                          &#x20;

&#x20;                                                                                               &#x20;

1- يتم ادراج رقم المستند وادراج المسلسل                                                                        &#x20;

&#x20; 2- من الممكن ادراج مسلسل طلب الصرف في حالة ربط الطلب بالعهدة                           &#x20;

&#x20;    3- يتم ادراج المشروع                                                                                                            &#x20;

4-يتم ادخال الفترة المراد البحث خلالها                                                                        &#x20;

## &#x20;تقرير العهدة المؤقتة <a href="#user-content-d9-81-d9-89-d8-ad-d8-a7-d9-84-d8-a9-d8-b9-d8-af-d9-85-d9-88-d8-ac-d9-88-d8-af-d8-aa-d8" id="user-content-d9-81-d9-89-d8-ad-d8-a7-d9-84-d8-a9-d8-b9-d8-af-d9-85-d9-88-d8-ac-d9-88-d8-af-d8-aa-d8"></a>

**يظهر ذلك التقرير كل العهد المؤقتة على موظف واحد أو أكثر و يتم البحث بالخطوات التالية :-**

1- يتم اختيار الموظف                                                                                                                       &#x20;

2- يتم اختيار المشروع                                                                                                                       &#x20;

3-يتم اختيار الفترة المراد البحث من خلالها                                                                        &#x20;

## تقرير حركات العهد المؤقتة <a href="#user-content-d8-aa-d9-82-d8-b1-d9-8a-d8-b1-d8-a7-d9-84-d8-b9-d9-87-d8-af-d8-a9-d8-a7-d9-84-d9-85-d8" id="user-content-d8-aa-d9-82-d8-b1-d9-8a-d8-b1-d8-a7-d9-84-d8-b9-d9-87-d8-af-d8-a9-d8-a7-d9-84-d9-85-d8"></a>

2- يتم اختيار العهد المراد عرض حركاتها                                                                                    &#x20;

3- يتم اختيار الفترة المراد البحث خلالها                                                                                          &#x20;
