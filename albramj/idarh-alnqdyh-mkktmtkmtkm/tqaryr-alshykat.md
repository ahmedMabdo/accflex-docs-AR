# تقارير الشيكات

&#x20;                                                                                                                             &#x20;

## تقرير اوراق الدفع&#x20;

&#x20;          هو تقرير يوضح   أوراق الدفع التى  تمت  على  البرنامج , و يتم البحث  عنها من خلال&#x20;

&#x20;                 بعدة طرق                                                                                                          &#x20;

&#x20;   **1- بحث بنوع الدفع**                                                                                                                              &#x20;

&#x20;      يتم اختيار نوع الدفع ( انشاءات-حسابات-موظفين -لوجيستك)                                                                          &#x20;

&#x20;       يتم اختيار المورد                                                                                                         &#x20;

**2- البحث بالحالة**                                                                                                                                           &#x20;

يتم اختيار الحالة ( تم تسليمه-  محصل-مرتد-ملغي -تم التوقيع )                                                                                       &#x20;

يتم ادراج التاريخ الخاص بالحاله المختارة                                                                                &#x20;

&#x20;    **3- البحث بالبنك**                                                                                                                &#x20;

&#x20;يتم البحث بالبنك                                                                                                       &#x20;

يتم البحث بنوع ورقة الدفع ( مفتوح- لحامله-للمستفيد-مغلق)                                                                                              <br>

يتم اختيار الحساب واسم الجهة                                                                                       &#x20;

&#x20;                                                                                  &#x20;

&#x20;      **4- البحث بالتاريخ**      &#x20;

&#x20;       يتم البحث بتاريخ الانشاء                                                                                                 &#x20;

يتم البحث بتاريخ الاستحقاق                                                                                     &#x20;

&#x20;          يتم البحث بتاريخ الاصدار                                                                                             &#x20;

## تقرير أوراق قبض  <a href="#user-content-d8-aa-d9-82-d8-b1-d9-8a-d8-b1-d8-a3-d9-88-d8-b1-d8-a7-d9-82-d9-82-d8-a8-d8-b6-5b-5d" id="user-content-d8-aa-d9-82-d8-b1-d9-8a-d8-b1-d8-a3-d9-88-d8-b1-d8-a7-d9-82-d9-82-d8-a8-d8-b6-5b-5d"></a>

هو تقرير يوضح أوراق الدفع التى تمت على البرنامج , و يتم البحث عنها  من  خلال   :-                                                                                                                        &#x20;

&#x20;    **1- بحث بنوع القبض**                                                                                                                               &#x20;

&#x20;      يتم اختيار نوع القبض  ( انشاءات-حسابات-موظفين -لوجيستك)                                                                          &#x20;

&#x20;       يتم اختيار العميل                                                                                                         &#x20;

**2- البحث بالحالة**                                                                                                                                           &#x20;

يتم اختيار الحالة ( في الخزينة-تحت التحصيل -  محصل -مرتد-ملغي -تحصيل مباشر  )                                                                                       &#x20;

يتم ادراج التاريخ الخاص بالحاله المختارة                                                                                &#x20;

&#x20;    **3- البحث بالبنك**                                                                                                                &#x20;

&#x20;يتم البحث بالبنك                                                                                                           &#x20;

بتم البحث بخزينة   الشيكات                                                                                             &#x20;

يتم البحث بنوع ورقة القبض  ( مفتوح- لحامله-للمستفيد-مغلق)                                                                                              <br>

يتم اختيار الحساب واسم الجهة                                                                                       &#x20;

&#x20;                                                                                  &#x20;

&#x20;      **4- البحث بالتاريخ**      &#x20;

&#x20;       يتم البحث بتاريخ الانشاء                                                                                                 &#x20;

يتم البحث بتاريخ الاستحقاق                                                                                         &#x20;

يتم البحث بتاريخ الاستلام                                                                                                &#x20;

&#x20;                                                                                     <br>

## تقرير حالة الشيكات&#x20;

## &#x20;**يوضح ذلك التقرير حالة جميع الشيكات من حيث أنه قبض أو دفع**                                                                                      &#x20;

**يظهر التقرير حالة القبض ( في الخزينة-تحت التحصيل -  محصل -مرتد-ملغي -تحصيل مباشر)**

**يظهر التقرير حالة الدفع (تم تسليمه-  محصل-مرتد-ملغي -تم التوقيع)**  &#x20;

&#x20;  يتم البحث عن التقرير من خلال :-                                                                       &#x20;

<mark style="color:blue;">**1-بحث بالنوع**</mark>                                                                                                                                      &#x20;

يتم تحديد النوع من حيث ( دفع-قبض )                                                                      &#x20;

<mark style="color:blue;">**2- البحث بالحساب**</mark>                                                                                                                              &#x20;

يتم اختيار الحساب الذي تم من خلاله العمليات                                                                    &#x20;

<mark style="color:blue;">**3- البحث بالتاريخ**</mark>                                                                                                                            &#x20;

&#x20;بتاريخ الانشاء                                                                                                                                     &#x20;

تاريخ الاصدار                                                                                                                                        &#x20;
