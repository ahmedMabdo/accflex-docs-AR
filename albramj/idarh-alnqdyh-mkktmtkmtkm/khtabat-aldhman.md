# خطابات الضمان -تقرير خطابات الضمان

## خطابات الضمان <a href="#user-content-d8-ae-d8-b7-d8-a7-d8-a8-d8-a7-d8-aa-d8-a7-d9-84-d8-b6-d9-85-d8-a7-d9-86-5b-5d" id="user-content-d8-ae-d8-b7-d8-a7-d8-a8-d8-a7-d8-aa-d8-a7-d9-84-d8-b6-d9-85-d8-a7-d9-86-5b-5d"></a>

**هو خطاب تقدمه شركة المقاولات لمالك المشروع ليضمن مالك المشروع لتنفيذ الأعمال بصورة كاملة , و فى حالة أن شركة المقاولات لم تكمل العمل أو حتى تنفذه , يحق لمالك المشروع أن يسحب قيمة الأموال المسجلة فى خطاب الضمان هذا من البنك كتعويض له نتيجة الخسائر من قبل شركة المقاولات**                                                                                                             &#x20;

**يتم انشاء خطابات الضمان بالخطوات التالية :-**                                                                                &#x20;

&#x20;   1- يتم اختيار نوع العميل ( حسابات-عملاء انشاءات   -عملاء مخازن-عملاء تسويق عقاري)                                                     &#x20;

2- يتم ادخال معلومات الخطاب وتشمل  ( رقم المستند   -تاريخ البداية والنهاية-العميل -نوع الخطاب ( ابتدائي -دفعه مقدمه -نهائي )-الوصف)                                                         &#x20;

3- يتم اختيار البنك  والقيمة                                                                                         &#x20;

4- يتم اختيار الغطاء ويشمل  تحديد نوع الغطاء قيمة ام نسبه  واختيار الحساب وادراج القيمة                                                                                    &#x20;

5- يتم ادراج الفوائد البنكية  وتشمل ادخال اسم الحساب ومركز التكلفه وادخال النوع نسبه اوقيمة                                                                         &#x20;

&#x20;        6- يتم ادراج مصارف الاصدار   وتشمل ادخال اسم الحساب ومركز التكلفه وادخال النوع نسبه اوقيمة                                                                                                      &#x20;

&#x20;           7- إمكانية إضافة     ملحقات لشاشة خطابات الضمان                                                                                                                &#x20;

## تقرير خطابات الضمان <a href="#user-content-d8-aa-d9-82-d8-b1-d9-8a-d8-b1-d8-ae-d8-b7-d8-a7-d8-a8-d8-a7-d8-aa-d8-a7-d9-84-d8-b6-d9" id="user-content-d8-aa-d9-82-d8-b1-d9-8a-d8-b1-d8-ae-d8-b7-d8-a7-d8-a8-d8-a7-d8-aa-d8-a7-d9-84-d8-b6-d9"></a>

**و يوضح التقرير كل تفاصيل الخطاب المقدم بمعلومية اسم البنك و القيمة المالية و قيمة الغطاء فى حالة عدم إكمال المشروع و اسم العميل صاحب المشرو ع**                                 &#x20;

**يتم البحث بالخطوات التالية**                                                                                                           &#x20;

1-يتم اختيار البنك                                                                                                     &#x20;

2- يتم اختيار المشروع                                                                                                &#x20;

&#x20;   3- يتم اختيار نوع الخطاب(ابتدائي-دفعه مقدمة-نهائي)                                                     &#x20;

&#x20;   4-يتم اختيار الفترة المراد البحث خلالها                                                                        &#x20;
