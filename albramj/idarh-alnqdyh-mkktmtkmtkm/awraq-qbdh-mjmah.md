# اوراق قبض مجمعه

**يتم انشاء اوراق قبض مجمعه  نوع حسابات بالخطوات التالية**                                                                        &#x20;

1- يتم اختيار نوع القبض ( حسابات )                                                                                             &#x20;

2- يتم اختيار الحساب  واسم الجهة يعتمد علي نوع القبض المختار                                           &#x20;

3- يتم اختيار خزينة الشيكات وكتابة اسم البنك                                                                                      &#x20;

4-يتم كتابة تاريخ الاستلام وتاريخ الاستحقاق                                                                      &#x20;

&#x20;  5- يتم كتابة قيمة كل ورقة قبض   ويظهر الاجمالي اتوماتيكي معتمد علي عدد الشيكات                                                                                    &#x20;

6-يتم اختيار فترة التباعد ومن خلالها يظهر تاريخ استحقاق كل شيك    وكذلك ادراج عدد  الشيكات                                                                            &#x20;

2- يتم اختيار العميل واسم الجهة يعتمد علي نوع القبض المختار  وكذلك قبض ل( مستخلص مالك-تسعير مشروع)                                         &#x20;
