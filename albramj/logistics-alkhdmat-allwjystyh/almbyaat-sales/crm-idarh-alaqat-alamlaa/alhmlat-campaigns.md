# الحملات (Campaigns)

الحملة (Campaign) تسجّل النشاط التسويقي الذي جاء منه العميل المحتمل — معرض تجاري، حملة إعلانية، برنامج إحالة، وما شابه. ربط حملة بعميل محتمل **اختياري** ولا يؤثر في أي سلوك آخر في النظام؛ الغرض منه قياس أي الحملات تُنتج أعمالاً فعلية. تنتمي الحملات إلى منظمة مبيعات.

## إنشاء حملة

اختر منظمة المبيعات (إدارة المبيعات - Sales Organization) أولاً — يطلب النموذج ذلك قبل السماح بالحفظ.

| الحقل | ملاحظات |
| --- | --- |
| الكود (Code) | مطلوب |
| اسم الحملة (Campaign name) | مطلوب |
| اسم الحملة باللغة الثانية | مطلوب |
| تاريخ البدء (Start date) | |
| تاريخ الانتهاء (End date) | |
| نشطة (Active) | تتوفر فقط بعد حفظ الحملة أول مرة |
| ملاحظات (Notes) | |

## ربط حملة بعميل محتمل

في نموذج [العميل المحتمل](alamlaa-almhtmlwn-leads.md)، اختر الحملة من حقل الحملة. يعرض المحدد الحملات النشطة فقط الخاصة بمنظمة مبيعات العميل المحتمل — إذا كان العميل المحتمل مرتبطًا بالفعل بحملة أصبحت غير نشطة، تبقى هذه الحملة ظاهرة على العميل المحتمل نفسه، لكنها لا تُعرض على عملاء محتملين آخرين.

## أداء الحملة (Campaign performance)

عند فتح حملة محفوظة، تظهر لوحة أداء بأربعة مؤشرات، محصورة بتلك الحملة ومنظمة مبيعاتها:

| المؤشر | ما الذي يُحتسب |
| --- | --- |
| العملاء المحتملون (Leads) | كل عميل محتمل تم إنشاؤه بهذه الحملة |
| العملاء المحتملون المحوّلون (Converted leads) | من هؤلاء، عدد من تم تحويله إلى عميل |
| الفرص البيعية (Opportunities) | الفرص البيعية المنشأة من عميل محتمل يحمل هذه الحملة |
| الفرص البيعية الفائزة (Won opportunities) | من هذه الفرص البيعية، عدد ما تم تحديده كفائز (Won) |
