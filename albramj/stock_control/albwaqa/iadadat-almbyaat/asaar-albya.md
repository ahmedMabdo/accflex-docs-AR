# أسعار البيع

## تعديل أسعار البيع  <a href="#user-content-d8-aa-d8-b9-d8-af-d9-8a-d9-84-d8-a3-d8-b3-d8-b9-d8-a7-d8-b1-d8-a7-d9-84-d8-a8-d9-8a-d8" id="user-content-d8-aa-d8-b9-d8-af-d9-8a-d9-84-d8-a3-d8-b3-d8-b9-d8-a7-d8-b1-d8-a7-d9-84-d8-a8-d9-8a-d8"></a>

**ويتم من خلالها تعديل اسعار البيع للاصناف المعروضة للبيع اذا وجد تغيير فى الاسعار -**

يتم اختيار تعديل الاصناف \
ثم اختيار تعديل اسعار البيع&#x20;

نختار ورقة عمل \
نقوم باختيار المخزن \
اختيار نوع السعر \
ثم اختيار الوحدة \
تحديد العملة \
و الضغط على تحميل الاسعار سوف يظهر لنا الشكل التالى \
نكتب السعر الجديد \
و أيضا حد سعر الجديد اذا وجد \
أو سحب الاسعار على اكسل والتعديل عليها ثم الرجوع والتحديث من ملف الاكسل\
ثم الضغط على حفظ&#x20;
