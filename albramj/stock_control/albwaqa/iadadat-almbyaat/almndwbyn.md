# المندوبين

## المندوبين <a href="#user-content-d8-a7-d9-84-d9-85-d9-86-d8-af-d9-88-d8-a8-d9-8a-d9-86-5b-5d" id="user-content-d8-a7-d9-84-d9-85-d9-86-d8-af-d9-88-d8-a8-d9-8a-d9-86-5b-5d"></a>

ومنها نقوم بتسجيل المندوبين القائمين على البيع وتسجيل عمولة كل واحد منهم كما يلى : <br>

![](<../../../../.gitbook/assets/1 (295).png>)

-نقوم باختيار الملحقات \
-ثم اختيار المندوب&#x20;

-فتح ورقة عمل جديدة \
-كتابة اسم المندوب \
-كتابة الكود \
-ثم كتابة رقم التليفون \
-كتابة العنوان \
-كتابة الرقم المستهدف للمبيعات المستحق علية العمولة \
-كتابة نسبة العمولة للمبلغ المستهدف\
-ثم نقوم باختيار المخزن \
-اختيار المدير\
-اختيار المنطقه \
-اختيار العملاء\
-ثم الضغط على حفظ

![](<../../../../.gitbook/assets/2 (55).png>)
