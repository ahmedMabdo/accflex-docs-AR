# قوائم الطعام

## قوائم الطعام  <a href="#user-content-d9-82-d9-88-d8-a7-d8-a6-d9-85-d8-a7-d9-84-d8-b7-d8-b9-d8-a7-d9-85-5b-5d" id="user-content-d9-82-d9-88-d8-a7-d8-a6-d9-85-d8-a7-d9-84-d8-b7-d8-b9-d8-a7-d9-85-5b-5d"></a>

و منها يتم إنشاء قوائم طعام محددة تضم أصناف تختلف كل قائمة عن القائمة الأخرى<br>

![](<../../.gitbook/assets/1 (280).png>)

-و يتم إنشاء قائمة جديدة بهذه الطريقة :

ادخال اسم للقائمة\
كود للقائمة \
اختيار الأصناف الملحقة بهذه القائمة\
ثم حفظ \
و يمكن التعديل على بيانات لكل قائمة \
أو مسحها كليًا
