# الإعدادات

## اعدادات النظام  <a href="#user-content-d8-a7-d9-84-d8-a5-d8-b9-d8-af-d8-a7-d8-af-d8-a7-d8-aa-5b-5d" id="user-content-d8-a7-d9-84-d8-a5-d8-b9-d8-af-d8-a7-d8-af-d8-a7-d8-aa-5b-5d"></a>

من خلال هذه الشاشة يتم ادخال بيانات الشركة                                                                                                                                                 &#x20;

1-ادخال اسم الشركة                                                                                                                                      \
2-ادخال رقم التليفون                                                                                                                           \
3-ادخال الفاكس                                                                                                                                          \
4-ادخال الايميل                                                                                                                                       \
5-ادخال العنوان                                                                                                                                                                              \
6-ادخال مسار حفظ تصميم التقارير                                                                                                         \
7-ادخال شعار الشركة                                                                                                                              &#x20;

8- ادخال بيانات الحسابات                                                                                                                                                                                                                                                                         \
9-الضغط على حفظ                                                                                                                      &#x20;

&#x20;                         &#x20;

## المستخدمين و الصلاحيات <a href="#user-content-d8-a7-d9-84-d9-85-d8-b3-d8-aa-d8-ae-d8-af-d9-85-d9-8a-d9-86-d9-88-d8-a7-d9-84-d8-b5-d9" id="user-content-d8-a7-d9-84-d9-85-d8-b3-d8-aa-d8-ae-d8-af-d9-85-d9-8a-d9-86-d9-88-d8-a7-d9-84-d8-b5-d9"></a>

**من خلال هذه الشاشة يتم إنشاء المستخدمين او التعديل علي مستخدمين تم انشاؤهم من قبل  و ربطهم بالصلاحيات**                                                                                                                         &#x20;

&#x20;**و يتم عمل مستخدم بهذه  الطريقة**                                                                                                          &#x20;

1-فتح ورقة عمل جديدة                                                                                                                        \
2-ادخال الاسم                                                                                                                                          \
3-ادخال رمز الدخول                                                                                                                                \
4-ادخال الهاتف                                                                                                                                      \
5-ادخال العنوان                                                                                                                                       \
6-إمكانية وضع المستخدم غير فعال و عدم ظهوره في شاشه الدخول                                                  \
7-الضغط على حفظ                                                                                                                                 &#x20;

&#x20;                                                                                               &#x20;

**بتم التعديل علي مستخدم من خلال الخطوات التالية**                                                                             &#x20;

1- يتم اختيار المستخدم                                                                                                                              &#x20;

2-الضغط علي تعديل ويتم التوجيه الي شاشة الصلاحيات الرئيسية ليتم تعديل الصلاحيات                    &#x20;
